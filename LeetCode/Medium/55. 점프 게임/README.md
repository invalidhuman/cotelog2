### 문제 설명

정수 배열 `nums`의 첫 번째 인덱스에서 출발합니다. 각 원소는 현재 위치에서 앞으로 점프할 수 있는 최대 거리를 나타냅니다.

마지막 인덱스에 도달할 수 있으면 `true`, 도달할 수 없으면 `false`를 반환합니다.

### 제한사항

- `1 <= nums.length <= 10⁴`
- `0 <= nums[i] <= 10⁵`

### 입출력 예

| nums | result |
| --- | --- |
| `[2, 3, 1, 1, 4]` | `true` |
| `[3, 2, 1, 0, 4]` | `false` |

### 풀이

#### DFS with Memoization

현재 위치에서 가능한 가장 먼 점프부터 깊이 우선 탐색합니다. 이미 방문한 인덱스는 다시 탐색하지 않으며, 현재 위치에서 마지막 인덱스까지 바로 도달할 수 있으면 탐색을 종료합니다.

- 시간 복잡도: `O(n²)`
- 공간 복잡도: `O(n)`

#### Greedy

배열을 순회하면서 지금까지 도달할 수 있는 가장 먼 인덱스를 갱신합니다. 현재 인덱스가 이 범위를 벗어나면 마지막 인덱스에 도달할 수 없고, 최대 도달 가능 인덱스가 마지막 인덱스 이상이면 도달할 수 있습니다.

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(1)`
